## What you get

An MCP server gives the agents tools: search your wiki, read a ticket, query an internal API. You register it once per organization, and the agents that do the work (triage, fixers, the `@jeanclode-bot` planner, code review's analyzers and fact checker) can call it on every run.

JeanClode is only a client. It connects out to the server's URL the way Claude Code does when you add a remote server; it never hosts or starts one. Only remote (HTTP) servers are supported, not local `stdio` ones.

## Adding a server

**Integrations → your GitHub or GitLab organization → MCP servers → Add server.**

- **Name**: what the tools are listed under (`mcp__<name>__<tool>`). `memory` and `playwright` are reserved: JeanClode registers its own servers under those names.
- **URL**: the server's endpoint, e.g. `https://mcp.example.com/mcp`.

Then **Add auth** on the server if it needs one. A server with no auth is registered unauthenticated.

## Auth

The agent's MCP client sends a placeholder header; the sandbox proxy replaces it with the real credential on the way out, so the token never reaches the agent. A server takes:

| Auth type | What the proxy sends |
|---|---|
| API key / JWT | The key in a header, `Authorization: Bearer …` by default; header name and prefix are configurable |
| Basic auth | `Authorization: Basic …` from a username and password |
| OAuth2 | A token the proxy mints itself from the provider's token URL (client credentials, password or refresh token grant) and refreshes before it expires |
| No auth | Nothing: the host is only allowed through |

A server's tools sometimes call other hosts themselves. Add an auth for each of those hosts on the same server, and the proxy allows and authenticates them too. See [Credentials](/docs/skills-and-mcp/credentials) for how hosts and wildcards work.

## Checking it loaded

Each agent logs what its session actually loaded, including every MCP server and whether it connected (`mcp=[docs=connected, …]`). A server that fails to connect is listed with its status, and the run goes on without it.
