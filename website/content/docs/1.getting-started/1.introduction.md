## What is JeanClode?

JeanClode is a self-hosted autonomous coding agent that turns Sentry errors, GitHub issues, and GitLab events into pull requests, without human intervention. You can tag JeanClode in an issue, a PR, or a review thread and it responds accordingly.

## How You Can Use It

- **[CLI](/docs/getting-started/quickstart)**, Review a PR or summarize one from the terminal. No server required.
- **[Self-Hosted Platform](/docs/getting-started/admin-dashboard)**, Full webhook integration, Sentry support, live dashboard, and team management, including autonomous Sentry Fix and Issue Resolve. Deploy with Docker Compose.

## Supported Workflows

| Workflow | Trigger | What it does | CLI |
|----------|---------|-------------|-----|
| **Sentry Fix** | Sentry error alert | Fetches error context, traces the root cause, opens a fix PR | Platform only |
| **Issue Resolve** | GitHub / GitLab issue | Triages → implements → opens a PR per repo the fix touches | Platform only |
| **Code Review** | PR / MR opened or labeled | 7-agent pipeline posts inline fact-checked comments | ✓ |
| **PR Summary** | PR / MR opened or labeled | Rewrites the description with a summary of the change | ✓ |
| **JeanClode Respond** | `@jeanclode-bot` mention | Replies, pushes fixes, resolves threads, or routes to another workflow | Platform only |

A PR JeanClode opens doesn't stop at "opened": review posts findings, the bot works through them, a push sends it back through review, and it repeats until a pass comes back clean — then the people you picked get @-mentioned. See [Autonomous Loop](/docs/architecture/autonomous-loop).

::note
More workflows are on the way: Linear, Jira, and a Slack bot.
::

## Why JeanClode?

- **Autonomous**, listens to webhooks, opens PRs, no human trigger needed
- **Verified**, every fix has to clear the target repo's own CI before the agent can finish its turn
- **Fact-checked**, parallel analyzers + an adversarial FactChecker with fresh context
- **Sentry-native**, error context, stack traces, breadcrumbs all feed the agent
- **Self-hosted**, your code never leaves your infrastructure
- **It remembers**, corrections and repo gotchas persist across runs, see [Agent Memory](/docs/architecture/memory)
- **Powered by Claude**, Anthropic's Claude models via the Claude Agent SDK
