Review a pull request or rewrite its summary in under 5 minutes. No server required.

## Install

```bash
uv tool install jeanclode  # or: pip install jeanclode
```

## Run

Pass a PR or MR URL, JeanClode auto-detects the workflow:

```bash
# Review a pull request:
jeanclode https://github.com/org/repo/pull/15

# Summarize it instead:
jeanclode summary https://github.com/org/repo/pull/15
```

The terminal mode covers Code Review and PR Summary. For autonomous Sentry
Fix and Issue Resolve, see the [Self-Hosted Platform](/docs/getting-started/admin-dashboard).

On first run, JeanClode walks you through setting up your API key and preferences. Run `jeanclode config` at any time to update them.

## Options

```bash
--dry-run    Analyze only, don't push any changes
--debug      Verbose output with agent reasoning
--model      Override the model (sonnet, opus, haiku)
```
