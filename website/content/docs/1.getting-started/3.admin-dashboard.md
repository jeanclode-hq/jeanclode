The self-hosted platform adds webhook integration, Sentry support, a live dashboard, and team management on top of the CLI.

![JeanClode Dashboard](/docs/dashboard-overview.png)

## What You Get

- **Autonomous operation**, webhooks trigger workflows automatically, no CLI invocation needed
- **Sentry integration**, errors flow in from Sentry and PRs flow out, fully unattended
- **Issues & PRs dashboard**, browse processed issues and pull requests, trigger manual reviews
- **Leaderboards**, PR authors, LGTM counts, and active repositories at a glance
- **Team management**, invite members and manage workspace access
- **Admin setup page**, configure all credentials through the UI, no extra env vars needed
- **LLM credential pool**, several keys or subscriptions in priority order, with automatic failover when one hits its rate limit
- **Ready notifications**, pick who gets @-mentioned once a PR JeanClode opened has been through review and come back clean

## Setup Checklist

- [ ] Deploy: [Docker Compose](/docs/deployment/docker-compose) or [Kubernetes](/docs/deployment/kubernetes)
- [ ] Open `/admin` and configure your GitHub App (or GitLab), and your LLM key
- [ ] Sign in and connect your organizations from the **Integrations** page
- [ ] Optional: connect [Sentry](/docs/integrations/sentry) for autonomous error fixing
- [ ] Optional: [harden security](/docs/deployment/security-hardening) for production

::note
Prefer to wire up your GitHub App or GitLab credentials directly via environment variables instead of the admin page? See the [GitHub](/docs/integrations/github) or [GitLab](/docs/integrations/gitlab) integration guides.
::
